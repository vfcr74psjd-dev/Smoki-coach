Built for solo queue decisions.

The app focuses on information you can actually use between rounds instead of flooding the screen while you are playing.

01

Instant round plans

Get an immediate plan at the start of a round. Optional local AI can refine it without blocking the useful first answer.

02

CS2 GSI integration

Uses supported Game State Integration for map, round, score, economy, health and player-match state.

03

Review Lab

Import CS2 demos to review your deaths, exact demo positions and recurring problem areas after the match.

04

Session progress

Track K/R, survival, zero-kill rounds, multi-kills and recent sessions for your local player profile.

05

FACEIT context

Optionally connect a FACEIT Data API key to show profile, ELO and supported performance statistics.

06

Phone companion

Open a private LAN dashboard from a QR code on a phone connected to the same network.
