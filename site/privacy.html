Privacy

Last updated: 2 October 2026

Sm0ki Solo Coach is designed as a local-first Windows application. The project does not operate its own analytics, advertising, account or telemetry backend.

Local data

Your player profile, coach preferences, session history and locally saved integration settings are stored on your Windows PC under the app's local application-data folder.

Local AI

If you enable Local AI, prompts are sent to the Ollama service running on your own computer. Sm0ki Solo Coach does not require a paid cloud AI API for this feature.

FACEIT

If you choose to use FACEIT integration, the app contacts FACEIT's Data API to request supported public/profile statistics. A FACEIT API key you save is stored for the current Windows user using Windows-provided data protection. Do not share your API key publicly.

GitHub and updates

The app contacts GitHub to check the public update manifest, download releases and, in Review Lab, may load public map-radar assets. GitHub's own privacy terms apply to those requests.

Phone Companion

Phone Companion exposes a temporary token-protected HTTP page on your local network. It is intended for devices on the same trusted LAN/Wi-Fi network. It does not provide HTTPS transport.

Website

This website is a static GitHub Pages site. It does not include advertising cookies, analytics scripts or a custom tracking system.

CS2 and anti-cheat boundaries

The app uses legitimate CS2 Game State Integration and demo parsing. It is not designed to read hidden enemy memory, inject DLLs, automate aim/recoil/input, or bypass anti-cheat systems.

Contact / source

The project source and issue tracker are available on GitHub.
